DevPulse

Your GitHub PRs, Jira tickets and Claude Code sessions — live in the menu bar and the terminal.

Download for macOS Version 0.13.1 for macOS 27 or later. Read the manual.

What it does

One dashboard, two places

Your pull requests, review requests, Jira tickets and running Claude Code sessions in a menu bar popover, and the same data live in the terminal: type devpulse for a lazygit-style view. Every item opens with one click or one key.

Notifications that matter

A review request, a new comment, CI passing or failing, Claude Code waiting for you or done with its work. Switch each kind on or off; your own comments and bots you do not care about stay quiet.

Quick launcher

Press ⌥Space and type just a number, such as 2290: it is found in your pull requests, tickets and sessions. Or type gh 812 or jira 2290 and press Enter: the pull request or ticket opens in the browser.

Light footprint

One GitHub request per refresh, no timer for Claude Code sessions, a pause while the Mac sleeps, and a terminal view that redraws only when something changed.

Download

The disk image is signed and notarized by Apple, so it opens without security warnings. Drag DevPulse to Applications.
